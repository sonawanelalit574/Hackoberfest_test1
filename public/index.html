    How the cook behaves, and which open model

    This file is the cook's job description. Change it and the next plan follows the new instructions. Swap the model id for any other Transformers.js text-generation model. A bigger open model follows rules more carefully and takes longer on CPU.

    The cook is an open-weight model, loaded through Transformers.js and run on this CPU. The default is Qwen2.5-1.5B-Instruct. The profile never goes to a model API. After the weights are cached, set SECOND_PLATE_OFFLINE=1 and the app will refuse to fetch them again.
